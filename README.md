## Self-Driving Car Simulator (OpenGL)

A self-driving car simulator built using C++ and Modern OpenGL to demonstrate autonomous vehicle control using techniques such as PID, LQR, and state-space control. The project features real-time 3D rendering, Phong lighting, collision detection, obstacle avoidance, and dynamic camera control.
